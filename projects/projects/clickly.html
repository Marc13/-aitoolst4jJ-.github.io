Clickly — Chrome Extension

Counts your clicks per page + a tiny analytics dashboard.

Home Project Tutorials

What I built

A lightweight Chrome extension that increments a counter whenever you click on a page, and logs totals by URL.

Skills practiced

  • Chrome extension manifest & file structure
  • DOM events & content scripts
  • Local storage for simple analytics

Repo & install

  1. Clone or download the Clickly folder (coming soon to your public repo).
  2. Go to chrome://extensions → enable Developer mode → Load unpacked → select the folder.
